# Calculador de Días Vividos 🌟

Proyecto hecho con **Angular** + **Ionic** que permite calcular los días que una persona ha vivido desde su fecha de nacimiento hasta hoy.  

---

## 🔹 Tecnologías utilizadas

- **Angular** (Frontend)
- **Ionic** (Framework híbrido móvil)
- **TypeScript** (Lenguaje)
- **Node.js** (Entorno de ejecución)
- **Capacitor** (Opcional para desplegar en móviles)

---

## 🔹 Requisitos previos

- Node.js >= 16
- npm >= 8
- Ionic CLI
- Angular CLI

```bash
npm install -g @ionic/cli @angular/cli
